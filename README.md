## Projeto Calculadora — FinançApp

Este repositório contém o projeto de uma calculadora desenvolvida em Java como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.

O objetivo foi praticar operações matemáticas básicas e trabalhar com testes unitários, tratamento de erros, refatoração, documentação e organização de arquivos no GitHub.

## Estrutura do repositório

- "projeto_calculadora/" — contém o código-fonte da calculadora, os testes, as imagens, a documentação JavaDoc e o README completo do projeto.

## Branches

- "main" — versão principal do projeto.
- "Refatoracao" — branch criada para trabalhar nas alterações de refatoração do código.

## Tecnologias utilizadas

- Java
- JUnit 5
- Maven
- JavaDoc
- GitHub

## Documentação

Para conhecer os detalhes do desenvolvimento, as funcionalidades implementadas, os testes e a documentação, acesse o arquivo ""projeto_calculadora/README.md"" (projeto_calculadora/README.md).
