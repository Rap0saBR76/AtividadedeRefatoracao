Projeto Calculadora — FinançApp

Projeto acadêmico desenvolvido para praticar conceitos de Qualidade de Software, testes unitários, refatoração, documentação e versionamento com Git e GitHub.

Objetivo

Implementar e testar uma calculadora em Java, aplicando boas práticas de programação e refatoração de código.

Funcionalidades

- Adição ("+")
- Subtração ("-")
- Multiplicação ("*")
- Divisão ("/")
- Tratamento de divisão por zero
- Tratamento de operações inválidas

Tecnologias utilizadas

- Java
- Maven
- JUnit
- Git
- GitHub
- JavaDoc

Estrutura do projeto

O código-fonte, os testes e a documentação estão organizados na pasta "projeto_calculadora".

Documentação

A documentação técnica deve ser gerada com JavaDoc.

Testes

O projeto deve incluir testes unitários para as operações matemáticas, a divisão por zero e as operações inválidas.
